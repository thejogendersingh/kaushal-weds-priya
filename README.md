# चि० कौशल कुमार संग आयु० प्रिया लांबा — Wedding Invitation

Interactive digital wedding invitation for **Kaushal & Priya** (चि० कौशल कुमार संग आयु० प्रिया लांबा).

## ✨ Features Included

- **Interactive Envelope Opening**: Realistic 3D perspective hover & click opening animation with wax seal monogram.
- **Falling Petal Dynamics**: Continuous floating flower petals (daisies & rose petals) with natural drifting physics.
- **Interactive Scratch Card**: Interactive canvas where guests scratch to reveal the wedding date (*25th November 2026*).
- **Live Countdown Timer**: Real-time ticker counting down days, hours, minutes, and seconds to the celebrations (*25th November 2026, शाम 6:15 बजे*).
- **Ceremony Timeline (मांगलिक कार्यक्रम)**:

  - **भात**: 24 नवम्बर 2026, मंगलवार | प्रातः 11:15 बजे
  - **चाक भात**: 24 नवम्बर 2026, मंगलवार | अपराह्न 3:15 बजे
  - **बारात आगमन**: 25 नवम्बर 2026, बुधवार | शाम 6:15 बजे
  - **दुकाव**: 25 नवम्बर 2026, बुधवार | शाम 7:15 बजे
  - **प्रतिभोज**: 25 नवम्बर 2026, बुधवार | शाम 7:15 बजे से आपके आगमन तक
  - **आशीर्वाद**: 25 नवम्बर 2026, बुधवार | रात्रि 9:15 बजे
  - **पाणिग्रहण संस्कार**: 25 नवम्बर 2026, बुधवार | शुभ लग्न अनुसार

## 🚀 How to Run Locally

### Option 1: Using Python
```bash
python server.py
```
Then open `http://localhost:3000` or `http://127.0.0.1:3000` in your web browser.

### Option 2: Using npm / npx
```bash
npm start
```
